# Teen Motivation 5-Second Reel Audio

Drop 5-second punchline audio tracks, bass drops, or phonk/trap beats here.

### Supported Audio Formats:
- `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`

The pipeline automatically loops or trims to 5.0 seconds with seamless volume normalization (-16 LUFS) and soft head/tail fades.
