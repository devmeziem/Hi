# Teen Motivation 15-Second Opinion vs Reality Slam Audio

Drop 15-second cinematic or bass drop tracks here.

### Supported Audio Formats:
- `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`

### Structure:
- 0.0s - 7.0s: Suspense / doubt build-up
- 7.0s - 8.0s: Dramatic silence during blackout
- 8.0s - 15.0s: Massive sub-bass slam / retort drop

If you upload a track, the pipeline normalizes it to broadcast standards (-16 LUFS) and aligns it to the 15-second master reel.
